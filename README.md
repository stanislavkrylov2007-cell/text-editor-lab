# Лабораторная работа №1 — вариант 16 «Текстовый редактор»

Проект на Python 3.10+ для работы с документами и текстовыми блоками. Реализованы создание, просмотр, изменение и удаление документов и блоков; поиск; чтение и запись JSON/XML; собственные исключения; аннотации типов; ООП с наследованием и полиморфизмом. В проекте 13 прикладных классов и 5 классов исключений. Отчёт не включён.

## Файлы

| Файл | Назначение |
|---|---|
| `main.py` | Консольные команды и точка входа |
| `models.py` | Документ и виды текстовых блоков |
| `service.py` | CRUD и поиск |
| `storage.py` | Чтение и запись JSON/XML |
| `exceptions.py` | Собственные исключения |
| `docs/classes.puml` | UML-диаграмма, включая исключения |
| `data/sample.json`, `data/sample.xml` | Один и тот же пример данных в двух форматах |

## Запуск

Из корня проекта:

```powershell
python main.py import data/sample.json
python main.py list
python main.py show example1
python main.py add example1 heading "Новый раздел" --level 2
python main.py search редактор
python main.py export data/backup.xml
```

Рабочая база по умолчанию — `data/editor.json`. Другой путь задаётся перед командой: `python main.py --db другой.json list`.

## Команды

| Команда | Назначение |
|---|---|
| `new "Название"` | Создать документ и показать ID |
| `list` | Список документов |
| `show ID` | Показать документ и ID блоков |
| `rename ID "Название"` | Переименовать документ |
| `delete ID` | Удалить документ |
| `add ID paragraph|heading|quote|list_item "Текст" [--level N]` | Добавить блок |
| `edit ID BLOCK_ID "Текст"` | Изменить текст блока |
| `remove ID BLOCK_ID` | Удалить блок |
| `search "Фраза"` | Найти текст без учёта регистра |
| `export файл.json|файл.xml` | Сохранить копию каталога |
| `import файл.json|файл.xml` | Заменить рабочий каталог |

После изменения данные автоматически сохраняются. При ошибке программа выводит сообщение и возвращает ненулевой код. Импорт некорректного файла не меняет рабочую базу.
